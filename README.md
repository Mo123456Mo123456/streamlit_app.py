# 🤖 وكيل الذكاء الاصطناعي المتكامل
# Integrated AI Agent Program

برنامج وكيل ذكاء اصطناعي متكامل ومخصص مع واجهة مستخدم حديثة وقدرات متعددة.

An integrated and personalized AI agent program with a modern user interface and multiple capabilities.

## ✨ المميزات / Features

### 🌟 القدرات الرئيسية
- **💬 محادثة ذكية**: محادثة طبيعية مع الوكيل مع حفظ السياق
- **💻 مساعدة في البرمجة**: كتابة وتحليل وإصلاح الكود
- **📊 تحليل البيانات**: تحليل البيانات وإنشاء التقارير
- **🌐 الترجمة**: ترجمة النصوص بين اللغات
- **📝 التلخيص**: تلخيص النصوص الطويلة
- **❓ الإجابة على الأسئلة**: إجابات شاملة على الأسئلة

### 🛠️ الأدوات المتقدمة
- استخراج الكود من النصوص
- اكتشاف اللغة
- عد الكلمات والحروف
- استخراج البريد الإلكتروني والروابط
- تحليل قابلية القراءة
- استخراج الكلمات المفتاحية
- معالجة JSON

### 💾 إدارة الذاكرة
- حفظ تاريخ المحادثة
- تفضيلات المستخدم
- سياق المحادثة
- تصدير المحادثات

### 🎨 واجهة المستخدم
- تصميم حديث وجميل
- دعم اللغة العربية والإنجليزية
- إحصائيات تفاعلية
- أدوات متعددة في تبويبات منفصلة

## 🚀 التثبيت والتشغيل / Installation & Running

### 1. تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

### 2. تشغيل التطبيق

```bash
streamlit run streamlit_app.py
```

سيتم فتح التطبيق في المتصفح تلقائياً على العنوان: `http://localhost:8501`

## 📁 هيكل المشروع / Project Structure

```
/workspace/
├── streamlit_app.py      # واجهة المستخدم الرئيسية
├── ai_agent.py           # نظام الوكيل الأساسي
├── agent_tools.py        # الأدوات المساعدة
├── requirements.txt      # المتطلبات
├── README.md            # هذا الملف
└── agent_memory.json    # ملف الذاكرة (يُنشأ تلقائياً)
```

## 🎯 الاستخدام / Usage

### المحادثة الأساسية
1. افتح التطبيق في المتصفح
2. اكتب رسالتك في حقل الإدخال
3. اضغط "إرسال" أو Enter
4. سيستجيب الوكيل فوراً

### استخدام الأدوات
- **الترجمة**: استخدم تبويب "الأدوات" واختر "أداة الترجمة"
- **التلخيص**: استخدم "أداة التلخيص" في نفس التبويب
- **تحليل الكود**: استخدم "أداة تحليل الكود"

### الإحصائيات
- راجع تبويب "التحليلات" لرؤية إحصائيات المحادثة
- تحليل أنواع المهام
- تاريخ المحادثة الكامل

## ⚙️ الإعدادات / Configuration

يمكنك تخصيص الوكيل من خلال:
- الشريط الجانبي: إعدادات اللغة والمظهر
- إدارة الذاكرة: مسح أو تصدير المحادثات
- التفضيلات: حفظ تفضيلاتك الشخصية

## 🔧 التطوير / Development

### إضافة قدرات جديدة
يمكنك إضافة قدرات جديدة للوكيل من خلال:
1. تعديل `ai_agent.py` لإضافة معالجات جديدة
2. إضافة أدوات في `agent_tools.py`
3. تحديث الواجهة في `streamlit_app.py`

### تخصيص الوكيل
- تغيير اسم الوكيل في `ai_agent.py`
- إضافة قدرات جديدة في `AIAgent.capabilities`
- تخصيص التصميم في CSS داخل `streamlit_app.py`
