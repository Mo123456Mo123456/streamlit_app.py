# 💰 نظام الأرباح الآلي المتكامل | Automated Integrated Profit System

نظام متكامل لتحليل الأرباح الآلية بناءً على بيانات الناتج المحلي الإجمالي (GDP) من البنك الدولي.

An integrated automated profit analysis system based on GDP data from the World Bank.

## المميزات الرئيسية | Key Features

- 📈 **حساب الأرباح التلقائي**: حساب الأرباح المحتملة بناءً على معدلات نمو GDP
- 🎯 **إشارات التداول الآلية**: توليد إشارات شراء/بيع تلقائية بناءً على تحليل الاتجاهات
- 📊 **تحليل الأداء التفصيلي**: تحليل شامل للأداء المالي لكل دولة
- 🌍 **مقارنة الدول**: مقارنة متعددة الدول لتحديد أفضل الفرص الاستثمارية
- ⚠️ **إدارة المخاطر**: حساب مستوى المخاطر لكل استثمار محتمل

- 📈 **Automated Profit Calculation**: Calculate potential profits based on GDP growth rates
- 🎯 **Automated Trading Signals**: Generate buy/sell signals based on trend analysis
- 📊 **Detailed Performance Analysis**: Comprehensive financial performance analysis for each country
- 🌍 **Country Comparison**: Multi-country comparison to identify best investment opportunities
- ⚠️ **Risk Management**: Calculate risk levels for each potential investment

## التثبيت والتشغيل | Installation & Running

1. تثبيت المتطلبات | Install requirements:

   ```bash
   pip install -r requirements.txt
   ```

2. تشغيل التطبيق | Run the app:

   ```bash
   streamlit run streamlit_app.py
   ```

## كيفية الاستخدام | How to Use

1. **إعدادات الاستثمار**: حدد مبلغ الاستثمار ومدة الاستثمار من الشريط الجانبي
2. **اختيار الدول**: اختر الدول التي تريد تحليلها
3. **مراجعة النتائج**: استعرض الأرباح المتوقعة وإشارات التداول في التبويبات المختلفة

1. **Investment Settings**: Set investment amount and duration from the sidebar
2. **Select Countries**: Choose countries you want to analyze
3. **Review Results**: Browse expected profits and trading signals in different tabs
