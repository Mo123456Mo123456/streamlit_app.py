# 🤖 نظام التداول الآلي الذكي

نظام متكامل يعتمد على الذكاء الاصطناعي يعمل تلقائيًا لتحليل الأسواق واتخاذ قرارات التداول وجمع الأرباح.

## ✨ المميزات

- 🤖 **ذكاء اصطناعي متقدم**: استخدام نماذج Machine Learning للتنبؤ بحركة الأسعار
- 🔄 **عمل تلقائي بالكامل**: يعمل النظام بشكل مستقل دون تدخل يدوي
- 📊 **تحليلات شاملة**: مؤشرات تقنية متقدمة (RSI, MACD, Bollinger Bands, Moving Averages)
- 💰 **تتبع الأرباح**: نظام متكامل لتتبع الأداء والأرباح والخسائر
- 🌐 **تكامل APIs**: دعم التكامل مع منصات التداول وبيانات السوق الحقيقية
- 🎨 **واجهة حديثة**: لوحة تحكم تفاعلية باستخدام Streamlit
- ⚙️ **إدارة المخاطر**: نظام متقدم لإدارة المخاطر وحماية رأس المال
- 📈 **تقارير مفصلة**: رسوم بيانية وإحصائيات شاملة

## 🚀 البدء السريع

### المتطلبات

- Python 3.8 أو أحدث
- pip (مدير الحزم)

### التثبيت

1. **استنساخ المستودع**:
```bash
git clone <repository-url>
cd <repository-directory>
```

2. **تثبيت المتطلبات**:
```bash
pip install -r requirements.txt
```

3. **إعداد ملف البيئة** (اختياري):
```bash
cp .env.example .env
# قم بتعديل .env وإضافة مفاتيح API الخاصة بك
```

4. **تشغيل التطبيق**:
```bash
streamlit run streamlit_app.py
```

سيتم فتح التطبيق في المتصفح على `http://localhost:8501`

## 📖 دليل الاستخدام

### الواجهة الرئيسية

التطبيق يحتوي على 5 تبويبات رئيسية:

1. **🏠 الرئيسية**: نظرة عامة على الأداء والمراكز المفتوحة
2. **📈 التداول الآلي**: بدء وإيقاف التداول الآلي وتحليل السوق
3. **💰 الأرباح والأداء**: تفاصيل الأرباح والخسائر وسجل العمليات
4. **📊 التحليلات**: تحليلات فنية متقدمة ومؤشرات السوق
5. **⚙️ الإعدادات المتقدمة**: إعدادات المخاطر وإدارة البيانات

### بدء التداول الآلي

1. انتقل إلى تبويب **"التداول الآلي"**
2. اختر الرموز التي تريد التداول عليها (مثال: BTC, ETH, AAPL)
3. اضغط على **"بدء التداول الآلي"**
4. سيتم تدريب النموذج تلقائيًا ثم بدء التداول

### الإعدادات

يمكنك تخصيص النظام من خلال:

- **الشريط الجانبي**: إعدادات أساسية (رأس المال، الرموز، حجم المركز)
- **تبويب الإعدادات المتقدمة**: إعدادات المخاطر وإدارة البيانات

## 🔧 التكامل مع APIs

### Alpha Vantage (للأسهم)

1. احصل على مفتاح API مجاني من [Alpha Vantage](https://www.alphavantage.co/support/#api-key)
2. أضف المفتاح إلى ملف `.env`:
```
ALPHA_VANTAGE_API_KEY=your_api_key_here
```

### CoinGecko (للعملات المشفرة)

لا يحتاج إلى مفتاح API - يعمل مباشرة!

### Binance (للتداول الفعلي)

⚠️ **تحذير**: التكامل مع Binance للعرض التوضيحي فقط. لا تستخدم في الإنتاج بدون أمان كامل!

## 🧠 نماذج الذكاء الاصطناعي

النظام يستخدم **Gradient Boosting Regressor** للتنبؤ بأسعار المستقبلية بناءً على:

- المتوسطات المتحركة (SMA 20, SMA 50)
- مؤشر RSI
- مؤشر MACD
- Bollinger Bands
- تغيرات السعر والحجم
- التقلبات

## 📊 مؤشرات الأداء

النظام يتتبع:

- **قيمة المحفظة**: القيمة الإجمالية للمحفظة
- **العائد الإجمالي**: نسبة الربح/الخسارة
- **معدل الفوز**: نسبة العمليات المربحة
- **إجمالي الأرباح/الخسائر**: المبلغ الفعلي
- **عدد العمليات**: إجمالي عمليات الشراء/البيع

## ⚙️ إدارة المخاطر

النظام يتضمن:

- **Stop Loss**: حد أقصى للخسارة لكل عملية (افتراضي: 5%)
- **Take Profit**: هدف الربح (افتراضي: 10%)
- **حد حجم المركز**: الحد الأقصى لحجم كل مركز (افتراضي: 20%)
- **حد الخسارة اليومية**: حماية من الخسائر الكبيرة (افتراضي: 20%)

## 🔄 التداول الآلي

يمكن تشغيل النظام تلقائيًا باستخدام `automated_scheduler.py`:

```bash
python automated_scheduler.py
```

سيقوم النظام بـ:
- تشغيل دورات تداول تلقائية كل 15 دقيقة (قابل للتعديل)
- حفظ الحالة تلقائيًا
- مراقبة حدود المخاطر
- إيقاف نفسه تلقائيًا عند تجاوز الحدود

## 📝 ملاحظات مهمة

⚠️ **تحذيرات**:

1. هذا النظام للتعليم والاختبار فقط. لا تستخدمه مع أموال حقيقية دون اختبار شامل.
