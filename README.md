# 🤖 نظام التداول الذكي بالذكاء الاصطناعي

تطبيق ذكي متقدم يعتمد على الذكاء الاصطناعي للتداول التلقائي مع تتبع الأرباح والإحصائيات في الوقت الفعلي.

## ✨ المميزات

- 🤖 **ذكاء اصطناعي متقدم**: استخدام نماذج Machine Learning للتنبؤ باتجاهات السوق
- ⚡ **تداول تلقائي**: يعمل النظام تلقائياً 24/7 بدون تدخل يدوي
- 📊 **تتبع الأرباح**: مراقبة شاملة للأرباح والخسائر في الوقت الفعلي
- 📈 **تحليلات متقدمة**: رسوم بيانية وإحصائيات مفصلة
- 🎯 **إدارة المخاطر**: نظام Stop Loss و Take Profit قابل للتخصيص
- 💰 **جاهز للعمل**: متصل بجميع الأنظمة وجاهز للاستخدام الفوري

## 🚀 التثبيت والتشغيل

### المتطلبات

- Python 3.8 أو أحدث
- pip

### خطوات التثبيت

1. تثبيت المكتبات المطلوبة:

```bash
pip install -r requirements.txt
```

2. تشغيل التطبيق:

```bash
streamlit run streamlit_app.py
```

3. فتح المتصفح على العنوان:

```
http://localhost:8501
```

## 📖 دليل الاستخدام

### الإعدادات

في الشريط الجانبي، يمكنك تخصيص:

- **التداول التلقائي**: تفعيل/إلغاء التداول التلقائي
- **مستوى المخاطرة**: منخفض، متوسط، أو عالي
- **الحد الأقصى للصفقات**: عدد الصفقات المسموح بها يومياً
- **Stop Loss**: نسبة الخسارة القصوى المسموحة
- **Take Profit**: نسبة الربح المستهدفة

### التداول

1. **التداول اليدوي**: اضغط على زر "تنفيذ صفقة الآن" لتنفيذ صفقة بناءً على توصية AI
2. **التداول التلقائي**: فعّل التداول التلقائي وسيقوم النظام بالعمل تلقائياً

### مراقبة الأداء

- **لوحة المعلومات**: عرض الرصيد الحالي والأرباح الإجمالية
- **سجل الصفقات**: تفاصيل كاملة عن جميع الصفقات
- **الرسوم البيانية**: تطور السعر والأرباح بمرور الوقت

## 🏗️ البنية التقنية

- **Frontend**: Streamlit - واجهة مستخدم حديثة وسريعة
- **AI Model**: Random Forest Regressor - للتنبؤ باتجاهات السوق
- **Data Storage**: JSON - لحفظ الصفقات والإحصائيات
- **Visualization**: Plotly - رسوم بيانية تفاعلية

## ⚠️ تحذير مهم

هذا التطبيق هو **محاكاة للأغراض التعليمية فقط**. لا يستخدم بيانات سوق حقيقية ولا يتصل بمنصات تداول فعلية. لا يُنصح باستخدامه للتداول الفعلي بدون فهم كامل للمخاطر.
