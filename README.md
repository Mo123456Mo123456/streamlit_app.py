## 🌟 المميزات

### 📊 لوحة تحكم تفاعلية
- واجهة مستخدم عربية حديثة وجذابة
- رسوم بيانية تفاعلية متعددة
- تصميم متجاوب يعمل على جميع الأجهزة

### 💹 تحليل مالي شامل
- **تحليل الإيرادات**: تتبع المبيعات حسب المنتج والفئة والمنطقة
- **تحليل المصروفات**: مراقبة التكاليف التشغيلية بالتفصيل
- **حساب الأرباح**: هامش الربح الإجمالي وصافي الربح
- **مؤشرات الأداء**: KPIs رئيسية لقياس نجاح الأعمال

### 🤖 التوقعات الآلية
- توقعات الأرباح للأشهر القادمة
- مؤشر صحة الأعمال
- توصيات ذكية لتحسين الأداء
- تحليل الاتجاهات

### 📈 التقارير
- قائمة الدخل التفصيلية
- تقارير الأداء الشهري
- مقارنات بين الفترات
- تصدير البيانات

## 🚀 طريقة التشغيل

### 1️⃣ تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

### 2️⃣ تشغيل التطبيق

```bash
streamlit run profit_dashboard.py
```

### 3️⃣ فتح التطبيق

افتح المتصفح على العنوان: `http://localhost:8501`
