# 💠 Silver / سيلفر

**تواصل بعمق، شارك بخصوصية، كن على طبيعتك.**
*Connect deeply, share privately, be yourself.*

منصة تواصل اجتماعي حديثة تجمع التواصل الخاص، القصص، الفيديوهات القصيرة، المجتمعات، الاكتشاف والبث المباشر العام — بحساب واحد ينظّم جوانب حياتك داخل أقسام مستقلة.

## ✨ الفكرة الأساسية | Core idea

حساب واحد، خمسة أقسام اجتماعية — المستخدم ينشر مرة واحدة ويحدد أين يظهر المحتوى (**المنشور المتكيف**):

| القسم | Section | المحتوى |
|---|---|---|
| 🟢 دائرتي | My Circle | الأصدقاء المقربون (متابعة متبادلة) — محتوى لا يظهر للعامة |
| 🪞 واجهتي | My Front | الصفحة العامة: الصور، الفيديوهات، الأعمال |
| 💡 اهتماماتي | My Interests | محتوى مقترح حسب اهتمامات المستخدم |
| 👥 مجتمعاتي | My Communities | مجموعات منظمة بأدوار وإشراف |
| 📍 محيطي | My Surroundings | محتوى المدينة/المنطقة (بدون موقع دقيق أبدًا) |

## 🚀 التشغيل | Quick start

المشروع يتكون من ثلاث مكونات تشترك في نفس قاعدة البيانات ومنطق الأعمال (`silver/`):

| المكوّن | المسار | التشغيل |
|---|---|---|
| 🌐 نسخة الويب (Streamlit) | `streamlit_app.py` | `streamlit run streamlit_app.py` |
| ⚙️ خادم REST API للجوال | `backend/` | `uvicorn backend.main:app --host 0.0.0.0 --port 8000` |
| 📱 تطبيق iOS/Android (Expo) | `mobile/` | `cd mobile && npm install && npx expo start` — انظر `mobile/README.md` |

```bash
pip install -r requirements.txt -r backend/requirements.txt
./start.sh   # يثبت المتطلبات ويشغل الاختبارات ثم نسخة الويب
```

حساب المدير يُنشأ تلقائيًا عند أول تشغيل من متغيرات البيئة:

```bash
export SILVER_ADMIN_USERNAME=admin
export SILVER_ADMIN_EMAIL=admin@silver.local
export SILVER_ADMIN_PASSWORD='ChangeMe_123'   # غيّرها قبل الإنتاج
```

## ✅ المزايا المنفذة | Implemented features

- **حسابات حقيقية**: تسجيل/دخول بتجزئة PBKDF2-SHA256 مع ملح لكل مستخدم، أدوار (مستخدم/صانع محتوى/مشرف/مدير)، إيقاف وإغلاق حسابات.
- **الأقسام الخمسة** مع قواعد رؤية فعلية لكل قسم، و**المنشور المتكيف** الذي يستهدف عدة أقسام في نشرة واحدة.
- **مساعد ذكي** (اقتراح القسم والتصنيف والكلمات المفتاحية + تنبيه المعلومات الحساسة) — اقتراحات فقط، لا نشر تلقائي أبدًا.
- **القصص**: صلاحية 24 ساعة، جمهور (دائرتي/متابعون/الجميع)، إطار تيفاني للجديد ورمادي للمشاهد، عدّاد مشاهدات، رد على القصة برسالة خاصة، قصص مميزة في الملف.
- **منشورات** نص/صورة/فيديو/فيديو قصير مع إعجاب وتعليق وحفظ ومشاركة برسالة، ووسم المحتوى المنشأ بالذكاء الاصطناعي.
- **المجتمعات**: عام/بموافقة/بالدعوة، أدوار (مالك/مدير/مشرف/عضو)، طلبات انضمام، نشر داخلي.
- **الرسائل الخاصة**: محادثات ثنائية، طلبات رسائل من غير المتابعين، تثبيت/كتم/أرشفة، حذف رسالة، إعداد «من يستطيع مراسلتك» (الجميع/المتابعون/الأصدقاء/لا أحد).
- **البث المباشر العام**: عنوان وتصنيف ووصف، تعليقات مباشرة، طلبات ضيوف بقبول/رفض، عدّاد مشاهدين، إنهاء مع حفظ أو حذف التسجيل، ظهور في الاكتشاف وإشعار المتابعين. *(نقل الصوت/الصورة الفعلي يتطلب ربط مزود WebRTC في الإنتاج — البنية جاهزة للاستبدال.)*
- **الاكتشاف**: بحث (مستخدم/منشور/مجتمع)، مباشر الآن، رائج، حسابات ومجتمعات مقترحة، محتوى قريب.
- **الإشعارات** لكل الأحداث مع تحكم لكل نوع.
- **الخصوصية والأمان**: حظر، كتم، حساب خاص، إخفاء عدد الإعجابات، تغيير كلمة المرور، حذف الحساب.
- **البلاغات والإشراف**: 12 نوع بلاغ، لوحة إدارة (إحصاءات، معالجة البلاغات، إدارة المستخدمين والأدوار، مراقبة البثوث وإنهاؤها، إدارة التصنيفات، سجل تدقيق كامل).
- **العربية RTL والإنجليزية LTR** مع تبديل فوري، وهوية تيفاني `#0ABAB5` ببطاقات بيضاء وحواف مستديرة.

## 🧪 الاختبارات | Tests

سيناريو القبول الكامل (بند 27 من المواصفة) منفذ كاختبار آلي:

```bash
python3 -m unittest tests.test_silver_acceptance -v
```

## 🏗 البنية | Architecture

```
streamlit_app.py        # نقطة الدخول: الجلسة، التنقل، التوجيه
silver/
  db.py                 # مخطط قاعدة البيانات (SQLite → PostgreSQL جاهز)
  auth.py               # التسجيل والدخول وكلمات المرور
  services.py           # منطق الأعمال كاملًا (مستقل عن الواجهة)
  ai.py                 # اقتراحات المساعد (قواعد شفافة، قابلة للاستبدال بنموذج)
  i18n.py               # النصوص عربي/إنجليزي
  theme.py              # الهوية البصرية (تيفاني، RTL)
  components.py         # مكونات مشتركة (بطاقة المنشور، شريط القصص، نموذج البلاغ)
  views_*.py            # الشاشات: دخول، رئيسية، رسائل، اكتشاف، إدارة
docs/DATABASE.md        # توثيق الجداول والعلاقات
tests/                  # اختبار سيناريو القبول
```

فصل `services.py` عن الواجهة يجعل نقل نفس المنطق إلى Backend مستقل (FastAPI + PostgreSQL) لتطبيقات Android/iOS خطوة مباشرة — وهي خارطة الطريق للمرحلة التالية، مع مزود بث خارجي للفيديو المباشر وCDN للوسائط.
