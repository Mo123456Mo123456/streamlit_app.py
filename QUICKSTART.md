# 🚀 Quick Start Guide

## Get Started in 3 Steps

### Step 1: Install Dependencies

```bash
pip install -r requirements.txt
```

Or run the automated setup:

```bash
bash setup.sh
```

### Step 2: Launch the App

```bash
streamlit run streamlit_app.py
```

### Step 3: Open in Browser

The app will automatically open at: `http://localhost:8501`

## 🎯 First Time Using?

### Try This:

1. Click on "📊 AI Analysis" in the sidebar
2. Select 3-5 countries (e.g., USA, CHN, IND)
3. Adjust the year range to see trends
4. Read the AI-generated insights

### Then:

1. Go to "🎯 Investment Insights"
2. See the educational scoring system
3. Check the Risk vs Return chart

### Finally:

1. Visit "🔮 Predictions" 
2. Select a country
3. See AI predictions (remember: educational only!)
