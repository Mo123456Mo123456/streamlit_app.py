# 📱 Silver Mobile — تطبيق الجوال الأصلي (iOS + Android)

تطبيق React Native (Expo) بكود واحد يعمل على iPhone وAndroid، متصل بخادم Silver API.

## 1) تشغيل الخادم أولًا | Start the backend first

```bash
cd ..            # جذر المشروع
pip install -r backend/requirements.txt
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

## 2) ضبط عنوان الخادم | Point the app at your server

في `app.json` عدّل `expo.extra.apiUrl`:

- محاكي Android: `http://10.0.2.2:8000` (الافتراضي)
- محاكي iOS: `http://localhost:8000`
- هاتف حقيقي عبر Expo Go: `http://<عنوان-جهازك-على-الشبكة>:8000` مثل `http://192.168.1.10:8000`
- خادم إنتاج: `https://api.yourdomain.com`

## 3) التشغيل على هاتفك | Run on your phone

```bash
cd mobile
npm install
npx expo start
```

ثم امسح رمز QR بتطبيق **Expo Go** (متوفر في App Store وGoogle Play) — يعمل التطبيق فورًا على هاتفك.

## 4) بناء ملفات المتاجر | Build store binaries (APK / IPA)

يتم البناء عبر خدمة EAS المجانية من Expo (تتطلب حساب Expo):

```bash
npm install -g eas-cli
eas login
eas build --platform android   # ينتج AAB/APK للنشر على Google Play
eas build --platform ios       # ينتج IPA للنشر على App Store (يتطلب حساب Apple Developer)
```

## المزايا المنفذة في التطبيق

- تسجيل ودخول (JWT) + اختيار الاهتمامات والمدينة عند أول تشغيل
- الرئيسية: شريط القصص (إطار تيفاني للجديد/رمادي للمشاهد) + الأقسام الخمسة (دائرتي، واجهتي، اهتماماتي، مجتمعاتي، محيطي)
- المنشور المتكيف: نشر واحد لعدة أقسام، مع اقتراحات المساعد الذكي (القسم/التصنيف/الكلمات المفتاحية/تحذير المعلومات الحساسة)
- رفع الصور والفيديو من معرض الهاتف
- إعجاب، تعليق، حفظ، إبلاغ (12 سببًا)، حظر
- القصص بجمهور محدد + الرد على القصة برسالة خاصة
- الرسائل: قائمة محادثات، طلبات رسائل، دردشة بتحديث لحظي (polling كل 4 ثوانٍ)
- الاكتشاف: بحث، مباشر الآن، رائج، حسابات ومجتمعات مقترحة
- غرفة البث المباشر: تعليقات حية، طلب الانضمام كضيف، أدوات المضيف (قبول/رفض/إنهاء)
- الملف الشخصي: متابعة/إلغاء، رسالة، حظر، شبكة المنشورات
- الإشعارات والإعدادات (اللغة عربي/إنجليزي RTL/LTR، من يستطيع مراسلتك)

## اللحظية والإشعارات | Realtime & push

- **الرسائل والبث لحظية عبر WebSocket** (`/ws` لكل مستخدم و`/ws/live/{id}` لكل بث) مع polling بطيء كاحتياط عند انقطاع الاتصال.
- **إشعارات الدفع** تعمل عبر Expo: يسجل التطبيق توكن الجهاز تلقائيًا بعد الدخول، والخادم يرسل عند رسالة جديدة أو متابعة أو بدء بث.
- **الفيديو الحي**: الخادم يصدر توكنات LiveKit من `GET /live/{id}/rtc-token` عند ضبط متغيرات `LIVEKIT_*` — أضف `@livekit/react-native` واربطه (الصلاحيات جاهزة: المضيف والضيوف ينشرون، والمشاهدون يستقبلون).
