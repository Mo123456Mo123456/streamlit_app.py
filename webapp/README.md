# مَكسَب — إدارة الدخل الذكية

تطبيق ويب عربي (RTL) كامل لإدارة مصادر الدخل، بديل صادق وعملي عن تطبيقات "الربح التلقائي" الوهمية.

## المزايا
- **لوحة تحكم**: الرصيد الصافي، دخل ومصروفات الشهر، رسم بياني لآخر ٣٠ يومًا، توزيع الدخل حسب المصدر.
- **المعاملات**: تسجيل الدخل والمصروفات مع المصدر والتاريخ والملاحظات.
- **مصادر الدخل، المهام، الأهداف** مع متابعة التقدم.
- **أفكار دخل واقعية**: قائمة صادقة بطرق مشروعة (بدون وعود زائفة).
- عربي/إنجليزي، وضع داكن/فاتح، تصدير واستيراد نسخة احتياطية JSON.
- **بلا خادم**: يعمل بالكامل في المتصفح، والبيانات تحفظ محليًا (localStorage) — لا يمكن أن يظهر خطأ "Failed to fetch".

## التشغيل
افتح `index.html` مباشرة في أي متصفح، أو انشره على GitHub Pages / أي استضافة ثابتة.
