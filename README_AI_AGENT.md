# 🤖 نظام الوكيل الذكي المتكامل

## نظرة عامة

نظام ذكاء اصطناعي متكامل ومتعدد الوكلاء مع واجهة تفاعلية وقدرات متقدمة.

## ✨ المميزات

### 🎯 الوكلاء المتخصصون

1. **الوكيل الرئيسي (Master Agent)**
   - إدارة وتنسيق جميع الوكلاء
   - اتخاذ القرارات الإستراتيجية
   - توزيع المهام

2. **وكيل البحث (Research Agent)**
   - البحث عن المعلومات
   - جمع البيانات
   - التلخيص

3. **وكيل تحليل البيانات (Data Analyst Agent)**
   - تحليل البيانات الإحصائي
   - توليد الرؤى
   - إنشاء التقارير

4. **وكيل البرمجة (Coder Agent)**
   - كتابة الأكواد
   - مراجعة الأكواد
   - اختبار البرامج

5. **وكيل التخطيط (Planner Agent)**
   - وضع الخطط
   - إدارة المشاريع
   - تحديد الأولويات

6. **وكيل معالجة اللغات (Language Agent)**
   - الترجمة
   - تحليل المشاعر
   - استخراج الكلمات المفتاحية

### 🧠 نظام الذاكرة

- ذاكرة قصيرة المدى (Short-term Memory)
- ذاكرة طويلة المدى (Long-term Memory)
- قاعدة معرفة متكاملة
- سياق محادثة ذكي

### 💬 واجهة المستخدم

- واجهة Streamlit تفاعلية وجميلة
- محادثة في الوقت الفعلي
- لوحة تحكم شاملة
- إحصائيات مفصلة

## 🚀 التثبيت والتشغيل

### المتطلبات

- Python 3.8 أو أحدث
- pip

### خطوات التثبيت

1. **تثبيت المتطلبات:**

```bash
pip install -r requirements.txt
```

2. **تشغيل التطبيق:**

```bash
streamlit run ai_agent_app.py
```

3. **فتح المتصفح:**

سيفتح التطبيق تلقائياً على `http://localhost:8501`

## 📊 الأمثلة

### مثال 1: تحليل بيانات

```python
from ai_agent import MasterAgent, DataAnalystAgent

master = MasterAgent()
analyst = DataAnalystAgent()
master.add_sub_agent(analyst)

result = master.coordinate("حلل البيانات: [1, 2, 3, 4, 5]")
print(result)
```

### مثال 2: كتابة كود

```python
from ai_agent import CoderAgent

coder = CoderAgent()
code = coder.generate_code("اكتب دالة لحساب الأعداد الأولية")
print(code)
```

### مثال 3: البحث

```python
from ai_agent import ResearchAgent

researcher = ResearchAgent()
results = researcher.search_web("الذكاء الاصطناعي")
print(results)
```
