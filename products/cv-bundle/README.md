# حزمة السيرة الذاتية الاحترافية — عربي/إنجليزي 💼

منتج رقمي جاهز للبيع. ميزته التنافسية: **يُعدَّل في المتصفح مباشرة، بدون أي برنامج**، ثم يُحفظ PDF بضغطة زر — يعمل على الجوال والحاسوب.

## محتوى الحزمة (ملفات جاهزة)
| الملف | الوصف |
|---|---|
| `cv-modern.html` | سيرة ذاتية بعمودين وشريط جانبي ملوّن + مؤشرات مهارات |
| `cv-classic.html` | سيرة ذاتية كلاسيكية بعمود واحد، متوافقة مع أنظمة الفرز ATS |
| `cover-letter.html` | خطاب تقديم مرافق |

كل ملف: عربي/إنجليزي بضغطة زر، تعديل مباشر بالنقر على النص، حفظ PDF بمقاس A4، ويعمل بلا إنترنت.

## كيف يستخدمها المشتري (اكتبها له في المنتج)
1. افتح الملف بأي متصفح (Chrome مثلًا).
2. انقر على أي نص واكتب بياناتك.
3. زر «🌐» يبدّل بين العربي والإنجليزي، وزر «🖨️» يحفظ PDF.
